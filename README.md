# حِسبة

تقدير لجمارك وضريبة أمتعة المسافر وشحنات البريد بالريال السعودي. الواجهة عربية ومن اليمين إلى اليسار، والحساب محلي. السلع غير الموجودة في الجدول تُسعَّر من واجهة خارجية عبر الخادم، والمفتاح لا يصل إلى المتصفح.

## التشغيل

```bash
npm install
npm run dev
```

التطبيق يعمل على `http://127.0.0.1:5173/`.

ضع المفتاح في `.env` (انسخ الأسماء من `.env.example`). مفتاح Groq الذي يبدأ بـ `gsk_` يُوجَّه تلقائيًا إلى Groq. أعد تشغيل الخادم بعد تغيير ملف الخادم.

على Vercel أضف نفس الأسماء في إعدادات المشروع: `API_KEY` و`API_BASE_URL` و`API_MODEL`. ملف `.env` لا يُرفع مع النشر، لذلك الموقع يبقى بلا أسعار حتى تُحفظ هذه القيم هناك ثم يُعاد النشر.

```bash
npm test
npm run build
```

## ماذا يحسب

- **مسافر:** الإجمالي هو الجمارك والضريبة فقط. أول جوالين في الرحلة معفيان. باقي البضاعة تُعفى إذا كان مجموعها ٣٠٠٠ ريال أو أقل، وإذا تجاوزته تُحسب السلة كلها. الجوال الزائد ٥٪ جمرك ثم ١٥٪ ضريبة. اللابتوب بلا جمرك و١٥٪ ضريبة.
- **شحنة:** الإجمالي هو قيمة البضاعة مع الرسوم. حتى ١٠٠٠ ريال بلا جمرك، وفوقها ٥٪ ما عدا اللابتوب. رسم البيان ١٥ ريال حتى ١٠٠٠، ثم ٠٫١٥٪ بحد أدنى ١٥ وأقصى ٥٠٠، مرة واحدة. الضريبة ١٥٪ على القيمة والجمرك والبيان.
- **الوزن** يُعرض ولا يغيّر الرسوم. المقبول أكثر من صفر وحتى ١٠٠٠٠ كجم.
- السعر المكتوب في الجملة (مثل «٨٠٠ ريال») يُستخدم كما هو ولا يُرسل للواجهة.

الأرقام تقدير للتقديم، وليست تعرفة رسمية من هيئة الزكاة والضريبة والجمارك.
